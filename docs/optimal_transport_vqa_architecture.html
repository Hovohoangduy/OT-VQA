Optimal Transport as the visual evidence engine

Question-conditioned reasoning slots jointly allocate spatial, global, and null evidence through semi-relaxed OT. The answer decoder sees the image only through the resulting grounded slots.

Evidence boundary

The architecture and numerical tests are implemented. No VQA accuracy improvement has been measured yet.

Required conclusion rule: attribute an improvement to OT only after the OT model beats the matched slot-softmax model across paired seeds and on the held-out test split. A comparison with native Cross-Attention alone mixes routing and architecture effects.

The text encoder initializes and updates the reasoning slots. Every visual contribution to decoder memory is computed from a transport-weighted readout; there is no parallel raw-image attention route.

General evidence bank

Spatial

Patch detail

Appearance plus checked two-dimensional ViT patch coordinates supports local and spatial evidence.

Global

Whole scene

A masked summary supports scene, layout, weather, and other broad questions.

Null

Missing evidence

A bounded null preference lets a slot report that its requested evidence is unavailable.

Objects may be represented in patches, but object detection and scene graphs are not assumptions of the architecture. OCR and multi-scale features remain future evidence-bank extensions.

Semi-relaxed OT core

min_P  <P,C> + ε Σ P(log P − 1) + τ KL(Pᵀ1 || b)
s.t.   P ≥ 0,  P1 = a
TermRole
CQuestion/slot-conditioned cosine cost over evidence.
aHard uniform slot budget; each slot receives exactly its assigned mass.
bSmoothed question-conditioned visual preference with bounded null mass.
τStrength of coordination through the shared visual marginal.
εEntropy and routing temperature.

At τ=0, rows equal independent softmax routing exactly. Sinkhorn calculations disable autocast and run in float32. Masked columns use a finite internal log floor for stable gradients and return exactly zero mass.

Two-step reasoning

Each step computes a new cost and plan, reads appearance and spatial moments, preserves spatial/global/null mass, and updates slots with a recurrent cell, slot self-attention, question attention, and a feed-forward block.

S⁰ = LayerNorm(slot identity + projected question)
Pᵗ = SemiRelaxedOT(cost(Sᵗ, evidence, question))
Eᵗ = Σ Pᵗ · evidence / slot budget
Sᵗ⁺¹ = Reasoner(Sᵗ, Eᵗ, spatial moments, type mass, question)

What is measured

Transport health

Hard-row error, fixed-point residual, finite and convergence rates, iterations, column KL, and cost scale.

Routing behavior

Normalized entropy, slot similarity, null fraction, evidence coverage, and final allocation plan.

VQA behavior

Generated EM/F1, loss, output diversity, majority rate, image/question shuffle sensitivity.

Efficiency

Latency per example, CUDA peak memory, parameter counts, and one- versus two-GPU execution metadata.

Verification

Local status: compile and the complete CPU unit suite pass. The suite checks finite gradients, exact hard rows, padding, the tau-zero identity, raw/cache agreement, generation, and strict checkpoint reload.

CUDA/MPS finite-forward checks, Kaggle two-rank smoke testing, full training, held-out evaluation, and latency measurement must run on the target environment. Software tests cannot establish an accuracy gain.
