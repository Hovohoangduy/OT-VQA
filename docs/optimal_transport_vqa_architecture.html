Only fusion method

Native Multi-Head Cross-Attention

Question tokens form queries; spatial patches form keys and values. The method learns task-specific visual grounding directly from the VQA objective.

Qh = Wq Q    Kh = Wk V    Vh = Wv V
A = softmax(Qh Khᵀ / √d_head)
Z = A Vh
H = LayerNorm(Q + Wo Z)
H = LayerNorm(H + FFN(H))

Visual mask

Padded patch logits become negative infinity before softmax.

Question mask

Padded word outputs and attention rows are forced to zero.

Teacher interface

The final layer can expose [B,heads,M,N] attention only when training or diagnostics requests it.

Answer generation

Causal Autoregressive Decoder

Training

input = [BOS,y₁,y₂,...]
target = [y₁,y₂,EOS,...]

Cross-entropy ignores PAD; label smoothing is training-only.

Inference

Begin at BOS, greedily append one token, block PAD/BOS for unfinished rows, stop at EOS or maximum length, and never provide the reference answer.

Uniform masked marginals permit a compact numerical kernel. A pooled similarity prefilter selects hard negatives; a detached FIFO queue supports small batches. Symmetric loss trains I2Q and Q2I ranking.

Cᵢⱼ = 1 − cosine(vᵢ,qⱼ)
score(V,Q) = − Σᵢⱼ PᵢⱼCᵢⱼ / max(ΣᵢⱼPᵢⱼ, 10⁻⁸)
Lteacher = ½[CE(S_I2Q/T,0) + CE(S_Q2I/T,0)]
Known weakness: mass normalization discards UOT coverage. A mismatched pair may score well by transporting little mass through coincidentally similar tokens. The next redesign will use global-first alignment and the complete regularized UOT energy.

Stage 2

Soft Attention Distillation

The positive teacher plan is detached and normalized across patches for each valid word. It supervises the mean final-layer student attention, never the attention logits directly.

T = normalize_patches(stopgrad(Pᵀ))
S = normalize_patches(mean_heads(A))
Lot = KL(T || S)
Ltotal = Lanswer + λ(epoch) Lot

The selected best.pt contains only the student. Therefore a successful experiment still has native Cross-Attention inference latency.

Compute

Single GPU and Two-GPU DDP

Single process

CUDA_VISIBLE_DEVICES=0 python train.py ...

Two T4 GPUs

CUDA_VISIBLE_DEVICES=0,1 torchrun --standalone --nproc_per_node=2 train.py ...

Each DDP rank owns a training shard and model replica. Gradients and training metrics are synchronized. Rank zero alone evaluates the complete validation set and writes checkpoints; gate and early-stop decisions are broadcast.
